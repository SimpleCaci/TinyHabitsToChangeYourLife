# Tiny Habits to Change Your Life

A small interactive web grid that turns ten everyday wellness ideas into a simple visual checklist.

## Tech stack

- HTML
- CSS
- Vanilla JavaScript

## Habits represented

The interface covers movement, device boundaries, meals, breaks, fruits and vegetables, meditation, hydration, sleep, walking, and social connection.

## Run locally

Open `index.html` in a modern browser. No installation or build step is required.

## Status

Early front-end prototype. It demonstrates the interaction concept, while persistence, clearer completion feedback, responsive polish, and accessibility are natural next improvements.

## Next steps
